# Crônicas da Manutenção — Fase 7
Site estático (sem build). Na Vercel: New Project > importar a pasta/repositório > Deploy (Framework: Other).
Colunas lidas da planilha: Número da OS, Tipo de OS, Título, Trabalho, Data de início programada, Data de conclusão, Descrição.
Notificações: exigem HTTPS (a Vercel já fornece). No iPhone, instale na tela inicial (Compartilhar > Adicionar à Tela de Início).
Som ambiente: audio/taverna.mp3 (loop, começa no primeiro toque). Para trocar, substitua o arquivo mantendo o nome. Sem o arquivo, o app usa um ambiente sintetizado.
